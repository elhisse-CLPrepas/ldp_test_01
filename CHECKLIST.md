# Checklist Avant Publication

- Le message principal est clair en moins de 5 secondes.
- Le bouton principal envoie vers le bon contact.
- Les liens email, telephone et site fonctionnent.
- La page est lisible sur mobile.
- Les couleurs respectent l'identite bleu, gold et nuances professionnelles.
- Le repository GitHub est connecte.
- GitHub Pages est active avec GitHub Actions.
- Une version `v1.0.0` est creee apres validation.
