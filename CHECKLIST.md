# Checklist Avant Publication

- Le message principal est clair en moins de 5 secondes.
- Le bouton principal envoie vers le bon contact.
- Les liens email, téléphone et site fonctionnent.
- La page est lisible sur mobile.
- Les couleurs respectent l'identité bleu, gold et nuances professionnelles.
- Le repository GitHub est connecté.
- GitHub Pages est activé avec GitHub Actions.
- Une version `v1.0.0` est créée après validation.
